# Readfirst design

Quiet and exact, like a well-made instrument. Warm graphite, ivory and hairlines. There is no glow, no gradient and no glass: if something looks like an AI landing page, take it out.

- **Colour:** graphite ground, ivory text, muted earth tones for status only. No hue is used for decoration.
- **Type:** the system face (San Francisco on Mac, Inter elsewhere). Large titles are light, not heavy.
- **One solid shape:** the ivory pill marks where you are: the tab, the current setup step, the main button. Everything else is outline.
- **Motion is the flourish:** shared elements morph between pages through `ViewTransition`, content settles in with one curve, and everything stops under reduced motion.
- **Guidance:** a project shows `SetupStrip` until its first email is sent. It holds the one next action, so nothing else may be a primary button meanwhile.
